# CityLens Frontend

This directory contains the interactive map and scenario interface for [CityLens](../README.md).

## Run Locally

```bash
npm install
npm run dev
```

Use the local development URL printed in the terminal.

## Available Scripts

```bash
npm run dev      # Start the development server
npm run build    # Create a production build
npm run preview  # Preview the production build
```

## Configuration

Add required map-provider credentials to a local environment file using the variable names expected by the source. Never commit real tokens or secrets.

For the overall architecture, backend setup, demo limitations, and data disclaimer, see the [root README](../README.md).
